# لومرا — LUMERA

> انتخاب و رزرو متخصصان زیبایی و مراقبت؛ فارسی، راست‌به‌چپ و موبایل‌محور.

لومرا یک محصول نمایشی (portfolio build) برای خدمات حضوریِ زیبایی و مراقبت است: جست‌وجوی خدمت، مقایسه‌ی متخصص‌ها بر اساس امتیاز و قیمت، تماشای نمونه‌کار و نظرات، و رزرو زمان در شش گام. همه‌چیز روی داده‌ی ساختگیِ واقعی‌نما اجرا می‌شود و هیچ سرویس بیرونی یا کلید API لازم ندارد.

**پشته:** Next.js 16 (App Router + Turbopack) · React 19 · TypeScript (strict) · Tailwind CSS v4 · Zustand · Vazirmatn (self-hosted)

---

## اجرا

```bash
npm install
npm run dev        # http://localhost:3000  (dev, -H 0.0.0.0)
npm run build      # بیلد پروداکشن
npm run start      # سرو بیلد پروداکشن
```

اسکریپت‌های کمکی:

| دستور               | کار                                                         |
| ------------------- | ----------------------------------------------------------- |
| `npm run typecheck` | `tsc --noEmit`                                              |
| `npm run lint`      | ESLint (flat config، شامل قوانین React Compiler)            |
| `npm run format`    | Prettier روی `src/**/*.{ts,tsx,css}`                        |
| `npm run shots`     | گرفتن اسکرین‌شات موبایل/دسکتاپ از مسیرهای اصلی (Playwright) |
| `npm run qa`        | typecheck + lint + build به‌صورت پشت‌سرهم                   |

`shots` به سرویسی روی `http://127.0.0.1:3000` نیاز دارد، خروجی را در `.shots/` می‌نویسد و در صورت نیاز
اسکرین‌شات می‌گیرد و هر سرریز افقی یا خطای کنسول را گزارش می‌کند (خروج غیرصفر = مشکل). برای محیط‌هایی که
مرورگر آماده دارند: `SHOTS_BASE`، `SHOTS_ROUTES`، `SHOTS_VIEWPORTS`، `SHOTS_SCREENS`، `SHOTS_EXECUTABLE`
(مسیر باینری Chromium) و `SHOTS_NO_SANDBOX=1`.

## مسیرها

```
/                    خانه (هیرو، جست‌وجو، دسته‌ها، منتخب هفته، ظرفیت امروز)
/explore             کاوش: جست‌وجو، فیلتر، مرتب‌سازی، نمای کارتی/فهرستی
/explore?q=…&cat=…   همان‌جا با فیلترهای پیش‌پر؛ ?demo=empty|error برای حالت‌های خالی/خطا
/services            فهرست خدمات دسته‌بندی‌شده با قیمت و مدت
/specialists/[id]    پروفایل متخصص: خدمات، نمونه‌کار، نظرات، درباره (SSG)
/booking/[id]        ویزارد رزرو (خدمت ← متخصص ← تاریخ ← ساعت ← اطلاعات ← تأیید)
/booking/success     تأیید رزرو + شماره رزرو
/bookings            رزروهای من (آینده/گذشته) با لغو و جابه‌جایی زمان
/favorites           علاقه‌مندی‌ها
/account             پروفایل، آدرس‌ها، آمار
/notifications         مرکز اعلان‌ها
/support               پرسش‌های متداول و قوانین
/join                  فرم همکاری متخصص‌ها
```

## معماری

```
src/
  app/            مسیرهای App Router؛ هر صفحه یک server component نازک است
  components/     کامپوننت‌های دامنه (hero, specialist-card, booking-wizard, calendar …)
  components/ui/  سیستم کامپوننت: Button, Input, Badge, BottomSheet, Tabs, Toast…
  data/           داده‌ی ساختگی: ۱۵ متخصص، ۳۸ خدمت، ۲۰+ نظر، رزروها، اعلان‌ها
  hooks/          useToday, useIsBrowser, useReveal, useUi (media/scroll-lock/escape)
  lib/            fa.ts (اعداد و تاریخ فارسی), jalali.ts, specialist.ts, images.ts, rng.ts
  store/          Zustand + persist (localStorage) — رزروها، علاقه‌مندی‌ها، پروفایل، پیش‌نویس رزرو
public/img/       ۵۴ تصویر مشتق‌شده از ۹ مستر (اسکریپت: scripts/build-images.sh)
```

دو نکته‌ی ساختاری که در پروژه رعایت شده:

- **داده، نه متن آماده.** شمارش‌ها، بازه‌ی قیمت، وقت‌های خالی و خلاصه‌ی امتیازها همه از خودِ داده محاسبه می‌شوند (`src/data/*` + `src/lib/specialist.ts`)؛ هیچ عددی در UI دستی نوشته نشده است.
- **رندر پایدار.** هیچ `setState` داخل effect برای «آماده شدن» وجود ندارد. مقدارهای وابسته به مرورگر با `useSyncExternalStore` (`useIsBrowser`) یا اصلاح پس از mount (`useToday`) مدیریت می‌شوند تا hydration نلنگد.

## تاریخ و عددِ فارسی

تقویم شمسی در `src/lib/jalali.ts` پیاده شده (هفته از شنبه) و رندر تاریخ‌ها از `src/lib/fa.ts` می‌آید: `jDateLong`، `jDateFull`، `relativeDay` («امروز»، «فردا») و `nearDay` (همان عبارت، فقط برای بازه‌ی نزدیک تا تاریخ تکراری ساخته نشود)، `timeLabel`، `durationLabel`، `faNum` و `faDec` (ممیز فارسی «٫»). قیمت‌ها با گروه‌بندی ایرانی (`٬`) و واحد «تومان» نمایش داده می‌شوند.

## هویت بصری

| توکن                              | مقدار                     | کاربرد                             |
| --------------------------------- | ------------------------- | ---------------------------------- |
| `--color-bg`                      | `#0D0B10`                 | پس‌زمینه                           |
| `--color-surface-2/3`             | `#17131D` → `#21182A`     | کارت‌ها (سه سطح)                   |
| `--color-ink` / `muted` / `faint` | `#F7F3F8` / `#AAA1B2` / — | متن                                |
| `--color-accent`                  | `#C96CFF`                 | فقط اکشن اصلی، تب فعال، انتخاب‌شده |
| `--color-mint`                    | `#6EF2D0`                 | تأیید، زمان آزاد، وضعیت موفق       |
| `--color-rose`                    | `#FF7A9E`                 | علاقه‌مندی، هشدار ظریف             |

قاعده‌ها: لبه‌های ۱ پیکسلی و کم‌رنگ (`border-line`)، سه شعاع (`rounded-xs/md/lg`)، سایه‌ی بسیار کنترل‌شده، بدون گلاسمورفیسم و بدون گرادیان تزئینی. تایپوگرافی Vazirmatn با کنتراست وزن شدید (`font-light` در برابر `font-extrabold`) و سرتیترهای کوتاه. حرکت‌ها محدود به `rise`، `fade`، `sheet`، `pop` و reveal هنگام اسکرول است و همگی زیر `motion-safe` / `prefers-reduced-motion` خاموش می‌شوند.

`scripts/build-images.sh` از چند تصویر master، واریانت‌های لازم (کادر مربع، کاور عریض، کراپ چهره) را با ImageMagick می‌سازد؛ اجرا فقط در صورت تغییر مسترها لازم است. تصویر اشتراک‌گذاری `public/img/og-1200.jpg` هم با همان ابزار ساخته شده و عمداً فقط واژه‌ی لاتین `LUMERA` را دارد: در محیط هدلس، فونت فارسی برای شکل‌دهی متن در دسترس نیست.

## دسترس‌پذیری و جزئیات محصول

- `dir="rtl" lang="fa"` روی `html`، لینک «پرش به محتوای اصلی»، لیبل فارسی برای همه‌ی کنترل‌های تصویری.
- کاشی‌های تاریخ `role="gridcell"` با `aria-selected` و زمان‌ها `aria-pressed`؛ حداقل اندازه‌ی هدف لمسی ۳۶ پیکسل (اکشن‌های اصلی ۴۴+).
- مودال‌ها و شیت‌ها: بستن با `Escape`، قفل اسکرول body، فوکوس داخل پنل.
- حالت‌های پیاده‌شده: loading (skeleton)، empty، error، disabled، selected، active، booked، unavailable، verified، expired.
- دسکتاپ بازچینش می‌شود (هیرو دوسوتونه، فهرست دوسوتونه با ستون فیلتر چسبان، پروفایل با چیدمان ستونی)؛ بزرگ‌نمایی نسخه‌ی موبایل نیست.

## محدودیت‌های آگاهانه

داده‌ها ساختگی‌اند؛ شماره تماس‌ها، آدرس‌ها و تصاویر متعلق به اشخاص واقعی نیستند. درگاه پرداخت، احراز هویت و پیامک شبیه‌سازی می‌شوند (دکمه‌ی «تأیید و پرداخت» فقط یک رزرو محلی می‌نویسد).
